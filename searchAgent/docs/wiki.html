SearchAgent Documentation

This page is the canonical source for SearchAgent-specific terminology used by the HTML documentation and design specifications.

SearchAgent
SearchAgent is a manually activated Ploinky agent that runs normalized web searches for MCP callers and OpenAI-compatible clients. It owns provider selection for each request, provider credential lookup, input limits, provider execution, stable result fields, structured errors, and provider-readiness model descriptors. It does not choose a provider on behalf of a caller, persist a default provider, semantically rewrite queries, or guarantee identical ranking across independent search services.
AgentServer
AgentServer is the Ploinky runtime process started after SearchAgent's required local services are ready. It exposes the tools declared in mcp-config.json and runs the command handlers declared in manifest.json for Chat Completions and Models requests. AgentServer owns protocol transport and authenticated routing; the SearchAgent handlers own search input interpretation and response construction.
Normalized search result
A normalized search result is a provider response entry that contains stable title, url, and snippet fields. SearchAgent preserves useful provider-specific fields, substitutes the URL when a title is absent, removes entries without a URL, and deduplicates by exact URL before enforcing the result limit. Normalization aligns the response shape but does not make provider relevance scores or ranking methods equivalent.
DPU secret
A DPU secret is a provider credential stored by dpuAgent outside SearchAgent's non-secret settings file. The settings UI writes user secrets and grants read access to agent:proxies/searchAgent. Search execution asks the internal DPU tool only for the required and optional key names declared by the selected provider, and the settings response exposes masked hints rather than raw values. Environment values already supplied to the process take precedence.
SearXNG
SearXNG is SearchAgent's required loopback metasearch service for the searxng provider. The install hook creates a dedicated Python environment and a minimal settings file under the agent home, and startup waits for its JSON search endpoint on 127.0.0.1:8888. SearchAgent readiness fails when SearXNG or AgentServer is unavailable. SearXNG configuration beyond the generated minimal file remains owned by SearXNG defaults.
Google AI Mode browser pool
The Google AI Mode browser pool is an optional loopback sidecar that uses Chromium through puppeteer-core to execute google-ai-mode searches. SearchAgent starts it on port 8890 by default when its dependencies are available, monitors its process, and calls its search route through the provider adapter. A missing or failed pool removes that provider from model discovery but does not prevent the required SearXNG and AgentServer runtime from serving other providers.
Deep-research provider
The deep-research provider is a SearchAgent provider value that fans one query out to a configured list of API providers. It filters unknown providers and providers missing required secrets, runs the remaining providers concurrently with a bounded per-provider result limit, tolerates individual failures, adds sourceProvider, and deduplicates merged results by URL. It is not a separate MCP tool and cannot run when no selected provider is ready.
